
### Verfügbare Werte

| Bezeichnung        | Formelzeichen | Einheit       | Beschreibung                           |
| ------------------ | ------------- | ------------- | -------------------------------------- |
| Bandwidth          | $bw$          | $\frac{B}{s}$ | Bandbreite, Datenrate                  |
| maximum Size       | $msg_-size$   | $B$           | maximale Messagegröße                  |
| Frequency          | $f$           | $Hz$          | Ausführungsrate                        |
| maximum Gap        | $max_-gap$    | $s$           | größter Abstand zwischen zwei Messages |
| standard deviation | $std_-dev$    | $s$           | Schwankungen der Ausführungsrate       |
| Pup-Set            | $N_{pub}$     | $\mathbb{N}$  | Anzahl an Publishern                   |
| Sub-Set            | $N_{sub}$     | $\mathbb{N}$  | Anzahl an Subscribern                  |

### Kennzahlen für den Ressourcen-Überblick

### CPU

| Kennzahl                 | Formelzeichen      | Formel                               | Interpretation                                           |
| ------------------------ | ------------------ | ------------------------------------ | -------------------------------------------------------- |
| Callback Processing Load | $cb_-load$         | $=cb_-rate \times CB_-score$         | CPU-Last aller Topic-Callback-Ausführungen pro Sekunde   |
| Processing Density       | $process_-density$ | $=cb_-load/BW$                       | CPU-Aufwand pro Byte                                     |
| System Compute Load      | $cpu_-load$        | $=cb_-load+2\times serial_-pressure$ | geschätzte Gesamt-CPU-Last des Topics                    |
| Allocation Stress        | $alloc_-stress$    | $=f\times MSG_-score\times N_{sub}$  | Risiko für viele Speicherallokationen --> Heap-Aktivität |

### DDS

| Kennzahl                 | Formelzeichen      | Formel                           | Interpretation                          |
| ------------------------ | ------------------ | -------------------------------- | --------------------------------------- |
| Bandbreite pro Topic     | $bw_-calculated$   | $=msg_-size \times f$            | Datenmenge pro Sekunde                  |
| DDS Load                 | $dds_-load$        | $= bw \times N_{sub}$            | Datenverteilungsaufwand                 |
| Callback rate            | $cb_-rate$         | $=f \times N_{sub}$              | Callbackausführungen pro Sekunde        |
| Complexity Load          | $msg_-complexity$  | $=bw \times MSG_-score$          | Systembelastung durch Message-Struktur  |
| De-/Serialization Stress | $serial_-pressure$ | $=msg_-complexity\times N_{sub}$ | De-/Serialisierungsaufwand der Messages |

### Speicher

| Kennzahl                | Formelzeichen   | Formel                          | Interpretation           |
| ----------------------- | --------------- | ------------------------------- | ------------------------ |
| Maximum Queue Size      | $queue_{basic}$ | $=msg_-size\times qos_-depth$   | Basis Queue-Größe        |
| Subscriber Queue Memory | $queue_{sub}$   | $=queue_{basic}\times N_{sub}$  | reservierter RAM         |
| Publisher Queue Memory  | $queue_{pub}$   | $=queue_{basic}\times N_{pub}$  | gespeicherte Sendepuffer |
| Memory Pressure         | $mem_-pressure$ | $=queue_{sub}\times QOS_-score$ | Speicherauslastung       |
| Memory Bandwidth        | $mem_-bw$       | $=bw\times N_{sub}$             | RAM-Durchsatz            |
| Structure Cost          | $struct_-score$ | $=msg_-size\times MSG_-score$   | Speicherkomplexität      |

### Timing

| Kennzahl          | Formelzeichen    | Formel                                     | Interpretation                                                |
| ----------------- | ---------------- | ------------------------------------------ | ------------------------------------------------------------- |
| Jitter Ratio      | $j_-risk$        | $=std_-dev*f$                              | relative Schwankung                                           |
| Worst Queue Delay | $q_-delay_{max}$ | $=\frac{Depth}{f}$                         | maximal mögliche Nachrichtenverspätung/-rückstand in Sekunden |
| Queue Growth Risk | $q_-risk$        | $=\frac{f}{Depth}$                         | Risiko eines Queueoverloads                                   |
| Real-Time Risk    | $rtk_-risk$      | $=j_-risk\times cb_-rate\times QOS_-score$ | Echtzeitgefährdung                                            |
| Staleness Risk    | $s_-risk$        | $=q_-delay_{max}\times QOS_-score$         | Gefahr veralteter Daten                                       |
